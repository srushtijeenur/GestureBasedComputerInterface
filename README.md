This project is a Python-based web application that allows users to control their computer using hand gestures.  
It uses computer vision to track hand movements and convert them into mouse actions.

## Overview
The application uses a webcam to detect gestures in real-time, enabling control of the mouse pointer and clicks without physical contact.

## Features
- Real-time hand tracking using OpenCV and MediaPipe
- Mouse movement and click simulation
- Gesture recognition for specific actions
- Cross-platform support (Windows, Linux)
